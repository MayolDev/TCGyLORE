## 2025-02-20 - Unused Relationships Payload Optimization
**Learning:** In Inertia.js applications, controllers often eager load all relationships by default, even if the frontend index view only uses a subset of them. This causes unnecessary database queries and massive JSON payload serialization overhead. Furthermore, for the relationships that are used, often only `id` and `name` are needed.
**Action:** When optimizing Inertia controller `index` methods, check the corresponding `.tsx` file to verify exactly which relationships and properties are accessed. Constrain the `with()` array to only the necessary relationships and select only the required columns (e.g., `with(['relation:id,name'])`). This drastically reduces the memory footprint and the JSON payload size sent to the frontend.
