## 2025-02-23 - Inertia Data Over-fetching Anti-pattern
**Learning:** In Inertia.js applications, eager loading all relationships (e.g., `->with(['archetype', 'alignment', 'faction', 'edition', 'artist'])`) when rendering a view that only uses a subset of them (like `world`, `character`, `cardType`, `rarity`) causes significant over-fetching. This leads to increased memory usage on the backend and larger JSON payloads sent to the frontend, degrading both time-to-first-byte (TTFB) and client parsing time.
**Action:** When returning data to an Inertia frontend, always audit the `.tsx` components (e.g., `Index.tsx`) to determine exactly which relationships and columns are required. Use Eloquent's column selection within `with()` (e.g., `->with(['world:id,name'])`) to restrict eager loading strictly to the utilized data.
