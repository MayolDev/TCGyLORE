## 2025-04-22 - Optimizing CardController::index Relationships
**Learning:** In the `CardController::index` method, eager loading relationships like `archetype`, `edition`, `artist`, `alignment`, and `faction` introduces unnecessary N+1 overhead and payload size, because these relationships are not actually rendered in the `Admin/Cards/Index` React component or its TypeScript types. Eager loading only the necessary fields (`id`, `name`) for used relationships (`world`, `character`, `cardType`, `rarity`) significantly improves query performance and reduces JSON response size.
**Action:** Always verify if eager loaded relationships in controllers are actually consumed by the frontend views, and restrict the columns selected using the `relation:id,name` syntax to optimize database querying.
