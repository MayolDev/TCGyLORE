## 2026-03-17 - Optimize large collection calculations in DashboardController
**Learning:** In `DashboardController::index`, grouping cards by rarity originally loaded all records into memory (O(N) operation) and then performed PHP-level grouping and counting. In addition, the `Card` model contains a naming conflict where the `rarity` attribute shadows the `rarity()` relation. Trying to use `$item->rarity` can unexpectedly trigger the attribute instead of the loaded relation.
**Action:** When performing aggregate functions with Eloquent, use `.select(foreign_key, DB::raw('count(*) as count'))->groupBy(foreign_key)->with(relation)` to leverage database-level groupings (O(R) memory operation, where R is the number of distinct groups). To access a loaded relation when a conflicting attribute exists, always use `$item->relationLoaded('relation_name') && $item->getRelation('relation_name')` to avoid accidentally invoking the attribute string value.
