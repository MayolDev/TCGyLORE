## 2026-03-11 - Eloquent String/Relationship Column Shadowing and Aggregate Grouping
**Learning:** When a string column (e.g. `rarity`) shadows a relationship method with the same name, accessing the property `$model->rarity` will return the string value instead of the related model, causing logic errors when grouping by relations in memory. Memory grouping on large collections (like `Card::all()`) is also O(N) and highly inefficient.
**Action:** Use database-level aggregations (`select('rarity_id', DB::raw('count(*) as count'))->groupBy('rarity_id')`) to transform O(N) memory operations into O(R) ones. To bypass attribute conflicts when accessing eager-loaded relations, explicitly use `$model->relationLoaded('rarity') && $model->getRelation('rarity')` instead of `$model->rarity`.
