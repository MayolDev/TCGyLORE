## 2024-05-24 - Database Schema Mismatch & Broken Migrations
**Learning:** The `cards` table schema in the database (string columns for relations like `card_type`) does NOT match the `Card` Eloquent model (integer foreign keys like `card_type_id`). The migration `2025_12_21_171052_update_cards_table_with_relations.php` is empty, leaving the table in a legacy state while the code expects the new state. This breaks factories and basic CRUD operations in tests.
**Action:** When testing `Card` related features, one must either fix the migration locally to allow tests to run (but not commit the fix if it's out of scope) or use `DB::table` to insert legacy-compatible data. Also, SQLite does not support `MODIFY COLUMN`, requiring `DB::getDriverName() !== 'sqlite'` checks in migrations.
