## 2026-04-10 - Eager Loading Optimization in CardController
**Learning:** The CardController's index method eagerly loaded 9 relationships ('world', 'character', 'cardType', 'rarity', 'archetype', 'alignment', 'faction', 'edition', 'artist') using `with()`, but the frontend Index component only uses a subset of these ('world', 'character', 'cardType', 'rarity'). Eager loading unused relationships unnecessarily increases memory usage, serialization overhead, and network payload size in an Inertia setup. Also, as per instructions, it is better to eager load only the 'id' and 'name' columns to improve performance.
**Action:** Remove unused relationships from the `with()` clause and restrict the selected columns for the needed relationships to just 'id' and 'name' (e.g. `world:id,name`) to minimize JSON payload and memory consumption.
