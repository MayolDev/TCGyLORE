## 2024-04-02 - Optimize cardsByRarity query in DashboardController
**Learning:** When calculating statistics like cards by rarity, the previous implementation fetched all records into memory and then grouped them using PHP. This is an O(N) memory operation which scales poorly as the number of records increases. Additionally, the `Card` model has a naming conflict where the `rarity` attribute (string column) shadows the `rarity` relationship method.
**Action:** Use database aggregation (`select('foreign_id', DB::raw('count(*) as count'))->groupBy('foreign_id')`) to perform grouping at the database level, transforming the memory usage to O(R) where R is the number of distinct groups. To safely access a shadowed relationship in collections, use `$model->relationLoaded('relationName') && $model->getRelation('relationName')` instead of dynamic properties.
