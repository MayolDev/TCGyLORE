## 2025-04-20 - Inertia Payload Optimization
**Learning:** In Inertia.js applications using Laravel, eagerly loading all Eloquent relationships (e.g., `->with(['archetype', 'edition', 'artist', 'alignment', 'faction'])`) on the index page when the React frontend only uses a subset (like `world`, `character`, `cardType`, `rarity`) causes massive bloat in the JSON payload sent to the client and triggers unnecessary database queries.
**Action:** When returning paginated Eloquent models via Inertia, specifically target the `with()` method to only include the relationships needed by the React component, and use column selection (`world:id,name`) to strip out unused data from the eagerly loaded models, significantly reducing memory usage, query execution time, and network payload size.
