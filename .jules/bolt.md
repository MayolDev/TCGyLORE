## 2026-03-10 - Shadowed Eloquent Relationship Workaround for Collections
**Learning:** In the `Card` model, the `rarity()` relationship method is shadowed by the string/enum `rarity` attribute on the table. In eloquent collections, trying to access `$card->rarity->name` fails or returns unexpected string data due to this conflict.
**Action:** When accessing shadowed relationship properties like `rarity` during PHP collection mapping, use `$model->relationLoaded('rarity') ? $model->getRelation('rarity') : null` to explicitly fetch the loaded related model, bypassing the attribute conflict. Also, shift complex O(N) model instantiation during collection `.groupBy` calculations to the database via `select('rarity_id', DB::raw('count(*) as count'))->groupBy('rarity_id')` to achieve O(R) time and memory scale.
