## 2024-05-18 - Optimize Card Rarity Distribution Calculation
**Learning:** Calculating large distributions using Eloquent Collections in PHP (e.g. `Card::all()->groupBy()->map()`) causes O(N) memory overhead because it instantiates an Eloquent model for every row in the table. Even with eager loading, the entire result set is pulled into memory.
**Action:** Always prefer database-level aggregations `select('foreign_key', DB::raw('count(*)'))->groupBy('foreign_key')` for calculating distributions. When dealing with shadowed relationship names like `rarity` on the `Card` model, safely resolve relationships using `$item->relationLoaded('rarity') && $item->getRelation('rarity')` rather than the property accessor to avoid string vs relation conflicts, and retrieve the distribution safely.
