## 2025-03-03 - Prevent XSS via SVG Uploads on Cards and Locations
**Vulnerability:** File upload fields in `CardController` (illustration) and `LocationController` (image) relied only on the Laravel `image` validation rule, which inherently permits SVG files. Allowing untrusted SVG file uploads can lead to Stored Cross-Site Scripting (XSS) because SVGs can execute embedded JavaScript when rendered directly by the browser.
**Learning:** The `image` validation rule is insufficient on its own when strict raster image types are required to prevent script execution. Relying on default validation logic can miss vector-based vulnerabilities.
**Prevention:** Always pair the `image` validation rule with an explicit MIME type restriction using the `mimes` rule *before* the `image` rule (e.g., `mimes:jpeg,png,jpg,gif,webp`) to strictly reject potentially dangerous files like SVG or executable wrappers masquerading as image files. Tests should upload a mocked `.svg` file to assert that validation explicitly catches it.
