## 2024-05-24 - [Accessible Toasts and Backward Compatibility in Shared Components]
**Learning:** Native `alert()` calls break the modern UX flow and cause accessibility issues. The standard pattern in this design system is using `sonner` for toast notifications (`import { toast } from 'sonner'`). When modifying heavily shared components like `ImageUpload` to enhance UX, maintaining legacy prop compatibility (`value`, `onChange`, `existingImage`) is critical to avoid cascading refactoring in parent forms. Additionally, using `focus-within` ensures custom dropzones are keyboard accessible.
**Action:** Always replace native alerts with `sonner` toasts, add `focus-within:ring-2` to interactive custom containers for keyboard navigation, and ensure new UI prop additions are optional or support legacy interfaces to maintain stability.
