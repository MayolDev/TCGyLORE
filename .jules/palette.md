## 2025-03-03 - Reemplazo de Native Alerts y Accesibilidad en Componentes Custom
**Learning:** El uso de \`alert()\` nativos bloquea la ejecución y ofrece una experiencia de usuario intrusiva, especialmente en validaciones asíncronas de formularios (ej. tamaño máximo de imagen). Además, las zonas de drop customizadas (divs) suelen carecer de feedback visual cuando se navega usando el teclado, dificultando la accesibilidad y cumplimiento de las pautas a11y.
**Action:** Reemplazar llamadas a \`alert()\` con notificaciones de tipo toast de la librería \`sonner\` configurada en el proyecto (\`toast.error()\`). Utilizar las clases \`focus-within:ring-2 focus-within:ring-primary focus-within:ring-offset-2\` en componentes contenedores (como las drop zones) para que el foco del input interno se refleje visualmente en el diseño completo.
